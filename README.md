# PAINEL DE ESTUDOS

App de acompanhamento do cronograma de estudos para os concursos do TRT8 e do TRT4 (Analista Judiciário, Área Judiciária).

Para instalar no iPad ou iPhone, abra https://annaesteroliveira.github.io/paineltrt/ no Safari e toque em Compartilhar > Adicionar à Tela de Início.

Os registros ficam guardados no próprio aparelho. Use a aba Backup para exportar uma cópia de segurança.
